# Shared store screenshots

These original 1320 x 2868 PNGs were supplied by the maintainer for the first
release. They show iOS inside an iPhone frame and are preserved without edits.
The maintainer has chosen to reuse this set for Android store listings too.

1. Conversation list
2. People Nearby
3. Light conversation
4. Dark conversation

The canonical files live in
`fastlane/metadata/android/en-US/images/phoneScreenshots/`, named `1.png`
through `4.png` in the order above. Both F-Droid and Zapstore read that Fastlane
directory. Reuse those files for other promotional material instead of keeping
duplicate image sets.
